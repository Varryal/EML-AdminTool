# Операции с optional-модами в AdminTool

## Редактирование группы

В модалке `Optional mods` состояние файла и принадлежность к группе — разные
решения:

1. Переключатель `Optional` только делает файл optional или mandatory.
2. После включения выберите существующую группу либо явно создайте новую.
3. Существующие группы показываются первыми; создание новой группы находится
   отдельным действием в конце списка.
4. Для группы проверьте ID, заголовок, описание, рекомендацию по умолчанию и
   число привязанных файлов. Смена ID обозначает новую логическую идентичность;
   сохранённый выбор игроков по старому ID не переносится.

Снятие optional-состояния не удаляет группу. Если у группы временно не осталось
файлов, она отображается как orphan-группа и сохраняет настройки до явного
удаления.

## Обновление версии мода

При замене файла существующего мода:

1. загрузите новый JAR в `mods/`;
2. включите для него `Optional`;
3. привяжите его к существующей группе с тем же `optionalId`;
4. проверьте состав группы и число файлов;
5. сохраните изменения и только после этого удаляйте старый JAR.

Создание новой группы для новой версии сбрасывает логическую decision surface
игроков и может применить `enabledByDefault` заново.

## Conflict при сохранении

`OPTIONAL_MODS_CONFLICT` означает, что опубликованный список или группы успели
измениться после открытия модалки. Не закрывайте диалог:

1. нажмите `Refresh list`;
2. просмотрите список изменений сервера;
3. проверьте, что ваши несохранённые заголовки, описания и назначения групп
   перенесены на свежий состав;
4. исправьте конфликтующие значения при необходимости и сохраните снова.

После успешного сохранения AdminTool возвращает новую revision, поэтому второе
изменение можно сохранить в том же открытом диалоге.

## Удаление группы

Удаление сначала только помечает группу. Панель оставляет её видимой, показывает
что будет удалено вместе с решениями игроков, и предоставляет `Undo deletion`.
Группа исчезает из sidecar только после сохранения с явным действием удаления.

При ошибке `OPTIONAL_METADATA_INVALID`, `OPTIONAL_GROUP_CONFLICT` или
`OPTIONAL_METADATA_READ_FAILED` изменения не публикуются. Исправьте данные либо
восстановите читаемый sidecar и повторите операцию после обновления списка.
